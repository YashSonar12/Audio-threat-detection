# 🎧 Audio Threat Detection System

An AI-based system that detects potential threats from audio input using Speech Recognition and Natural Language Processing (NLP).

---

## 🚀 Features

- Converts audio to text using speech recognition  
- Analyzes text using NLP  
- Detects threat-related keywords  
- Provides alert system  

---

## 🛠️ Tech Stack

Backend: Python  
Frontend: React (Vite)  

---

## ⚙️ How to Run

### Backend
cd backend  
pip install -r requirements.txt  
python main.py  

### Frontend
cd frontend  
npm install  
npm run dev
